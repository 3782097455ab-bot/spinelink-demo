# SpineLink 公开演示

肩颈康复辅助系统的产品外观、参考解剖图谱、桌面与移动活动演示。

**网站：https://3782097455ab-bot.github.io/spinelink-demo/**

- 桌面：网站根目录。
- 手机：`mobile/`。
- 解剖图谱：`anatomy/`，桌面主入口同时内嵌同一图谱。

田阳、周建宇共同提出与推进本项目。此仓库仅包含经过选择的公开展示资源；专利草案、完整技术资料和内部机构留在私有工程仓库。

## 本地查看

在site目录启动任意静态HTTP服务，例如 `python -m http.server 8080`，通过浏览器打开本机8080端口。网站使用相对路径，可部署到GitHub项目子路径，无需后台或API密钥。

活动演示使用浏览器生成的模拟数据，记录保存在当前浏览器；项目问答使用公开介绍条目。完整本地平台的设备通信和外部模型适配仍由私有工程维护。
